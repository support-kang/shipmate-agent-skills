# Inspirations and attribution

Babysit Dev is informed by, but does not vendor, the following projects:

- [nassimna/karpathy-guidelines](https://github.com/nassimna/karpathy-guidelines): think before coding, prefer simple solutions, make surgical changes, and define verifiable success criteria.
- [StarQuant/ponytail-skill](https://github.com/StarQuant/ponytail-skill): YAGNI, reuse existing code, prefer standard/native capabilities, and minimize the working diff.
- [kannthu/stem](https://gist.github.com/kannthu/016d5d41aea9eff55591738d3400e54b): state-machine orchestration from planning through pull-request babysitting.
- [ng/adversarial-review](https://github.com/ng/adversarial-review): independent adversarial reviewer lanes.

Ponytail is MIT licensed. Check each upstream project before copying or redistributing its text or code. This repository uses newly written workflow instructions rather than embedding upstream skill text.
